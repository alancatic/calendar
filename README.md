# Description:
  This project is a web-based interactive calendar built using HTML, CSS, and JavaScript. 
  It allows users to add and view events in a simple and visually clean layout. 
  The goal of this project is to Allow users to add and manage events easily,
  prevent overlapping events for better time management, 
  and enhance user engagement through interactive design

# Features:
### Event Management:
- Add events to specific dates
- View events clearly within the calendar
- Organized daily, weekly, and monthly structure
### Overlap Detection:
- Automatically detects conflicting events
- Provides instant feedback to prevent scheduling errors
### Interactive UI:
- Clean and modern design
- Hover effects to signal interactivity
- Event indicators for quick visual reference
### Event Modal:
- Popup modal for creating and viewing events
- Focused user interaction with background dimming

# Technologies Used:
### HTML:
- Calendar structure (table layout)
- Image header
- Event modal
### CSS:
- Layout styling
- Responsive design elements
- Hover and modal effects
- Event indicators
### JavaScript:
- Dynamic event storage
- DOM manipulation
- Modal interaction logic
- Event overlap detection algorithm

# Purpose:
  This calendar was created to provide a more organized and interactive way to 
  manage schedules compared to basic calendars.

# Future Improvements:
